📄

AppUpload

Document automation for merchant-services agents. Photograph a handwritten application, the voided check and the driver's license — Claude's vision model reads the handwriting and the server returns a typed application PDF plus a pre-filled coversheet. A second workflow turns menu photos into Clover inventory imports.

Production Ready Runs with its Node server Node / ExpressClaude vision pdf-libExcelJSPlaywright tests
Reads handwriting, checks & licenses
Citizens & Merrick forms auto-detected
Documents processed in memory, never stored
Mock mode previews the flow with no API key
Open AppUpload →

Full processing needs its Express backend: cd apps/appupload && npm install && npm start. The interface itself opens right here.

  • Auto-detects which handwritten form was photographed — Citizens (Priority/Citizens Bank) or Merrick Bank — with confidence scoring
  • Claude vision extraction that pulls each value from the most authoritative source: owner identity from the driver's license, bank/routing/account numbers from the voided check's MICR line, everything else from the application
  • Fills encrypted application PDFs by compositing prebuilt page images with a crisp selectable-text overlay, anchored to preprinted $ and % symbols
  • Generates a pre-filled coversheet and downloads a combined packet, application only, or coversheet only
  • Full review-and-edit form for every extracted field — owners, business, fees, volumes — before generating, including blank or unreadable fields
  • Menu-to-Clover workflow: photograph a restaurant menu and download the Clover inventory-import .xlsx filled with items, prices and categories
  • Editable menu table with add/remove rows and a restaurant-name field that names the spreadsheet
  • Drag-and-drop or camera-capture uploader (up to 15 images) with client-side downscaling and thumbnail previews
  • In-memory processing — uploaded documents are never stored on disk
  • Demo mock mode that previews the entire flow without an Anthropic API key

WPI Route

The team field-route planner. Managers sign in, create a team and share a 6-character join code; each agent gets a territory ZIP and a six-day route of merchant stops. Notes roll in live on the team ticker while managers export day reports and PDF route sheets.

Production Ready Single-file appSupabase realtime + RLS Netlify FunctionsGoogle Places API PWA + Service Worker
Entire app in one 2,238-line file
Live team sync via Postgres realtime
Hand-built PDF exporter, zero libraries
Installable iOS PWA with offline shell
Launch WPI Route →
  • Auto-generates a full 6-day route (up to 25 merchants/day, checkpoints every 5 stops) from an agent's territory ZIP via Google Places, filtered to small businesses under a 150-review cap
  • Best-effort scrapes each prospect's public website for a contact email and owner name
  • Team accounts on Supabase: email/password sign-in, create-a-team or join via 6-character code, row-level security per team
  • Silent live team sync via Postgres realtime, with per-team device caching and offline edits merged newest-wins
  • Animated live team-activity ticker above the header showing worked stops, deals, and checkpoints
  • Merchant stop cards with tap-to-call phone, tap-to-open Maps address, and tappable owner contact
  • One-tap notes that stamp the time, mark the stop worked, advance the Up-next marker, and feed day/week tallies
  • Copyable day report plus a hand-built PDF export of all six days — raw PDF written in JavaScript, no library
  • Manual paste-import of one business per line with owner name, second phone, and email auto-detected
  • Installable iOS PWA with offline shell, safe-area layout, and light/dark app icons that follow the in-app theme toggle

Statement Studio

A self-contained tool that builds financial-document PDFs — card-processing statements, bank statements, voided checks and verification letters — from form input, with a live preview that regenerates as you type. All data stays on the device.

Production Ready Offline PWApdf-lib + fontkit pdf.js importVendored — zero CDN calls localStorage autosave
5 PDF layout engines
Live preview on every keystroke
100% client-side — nothing leaves the page
Round-trips reference PDFs exactly
Launch Statement Studio →
  • Four switchable document styles — Voided Check, Card Processing Statement, Bank Statement, and Bank Letter — plus a legacy Billing Statement kept for import compatibility
  • Live PDF preview that regenerates on every keystroke, with a clean statement filename convention
  • Import an existing statement PDF and auto-populate every form field — auto-detects billing, card-processing and bank statement styles
  • Card Processing Statement with CMYK-banded funding-by-batch tables, per-card-type summaries, grouped fee schedule, and tax-reportable sales
  • Print-house artifacts reproduced: Intelligent Mail (IMb) barcode, OMR marks, and control codes
  • Voided check engine with MICR line, amount box, signature line and prominent VOID marking for direct-deposit/ACH verification
  • Bank Statement engine: masthead, account-summary box, Deposits & Credits / Withdrawals & Debits / Checks Paid tables with computed daily-balance summary
  • Bank verification letter with letterhead, account-holder block, verification body, and signature block
  • Upload a check, letter, or logo image — normalized to PNG — to lift branding onto generated output
  • Live fee arithmetic: line items auto-calculate from Volume×Rate or Fee×Count with category totals, tax and Amount Due recomputed live; the form autosaves to localStorage
